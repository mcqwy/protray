# 育苗盘网站

这是一个关于育苗盘的静态网站，包含产品展示、图片和视频资源。

## 项目结构

- `index.html`: 网站主页面
- `css/`: 样式文件目录
- `js/`: JavaScript文件目录
- `assets/`: 静态资源目录（图片、视频等）

## 部署说明

本项目已配置为自动部署到GitHub Pages。每次推送到main分支时，GitHub Actions将自动构建并部署网站。

## 使用方法

1. Fork此仓库到您的GitHub账户
2. 在GitHub仓库设置中启用GitHub Pages
3. 选择main分支作为源分支
4. 访问您的GitHub Pages URL查看网站
